# SpawnWP 0.5.33

This consolidated release contains all core changes developed after `0.5.32` before the public
release process was run. It replaces the provisional `0.5.34`–`0.5.42` development labels with one
stable, signed release.

Highlights:

- signed optional modules with atomic activation, lifecycle hooks, automatic least-privilege local
  credentials, portable nginx routing and full Cockpit management;
- managed and restricted demo provisioning, blueprint discovery, single-use admin links and
  lifetime accounting that starts after setup;
- compatibility support for the separately signed Demo Launcher beta, which provides Turnstile,
  CSRF protection, privacy-preserving limits, campaigns, a durable queue and expiring demo URLs;
- telemetry aggregation that separates observed, confirmed, provisional and anomalous installs,
  quarantines suspicious bursts and keeps email and dashboard data aligned;
- duplicate-port repair, updater fallback, expiry, provisioning-error and migration hardening;
- refreshed API, security, module and release documentation, public comparison content and the
  SpawnWP Deploy `0.3.6` distribution metadata;
- the Cockpit and public site loading fixes that prevent visible CSS/animation flicker.

Existing API clients retain their previous defaults (`standard` provisioning and `return`
credentials), and existing SpawnWP sites remain unchanged unless an operator explicitly updates
them.
