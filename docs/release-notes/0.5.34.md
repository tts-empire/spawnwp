# SpawnWP 0.5.34

This release adds the first version of the optional-module marketplace. The Cockpit can discover
free modules from a SpawnWP-curated catalog, verify its detached signature, and install a selected
package through the existing signed module manager. The catalog and package remain independently
hosted and signed, so a catalog outage cannot affect installed modules or the command-line flow.
