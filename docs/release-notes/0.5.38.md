# SpawnWP 0.5.38

Sensitive Cockpit actions now preserve WebAuthn transport hints and provide a direct password plus
authenticator/recovery-code fallback. Administrators working from a device without the registered
passkey no longer need to sign out before confirming an uninstall or other destructive action.
