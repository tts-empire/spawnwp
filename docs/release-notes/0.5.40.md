# SpawnWP 0.5.40

This release separates module integration removal from destructive data removal. Normal module
uninstall keeps module-owned state for a later reinstall; the new `--purge` option and Cockpit
“Uninstall and delete data” action request permanent removal of that state. A module can refuse a
purge while active resources still exist. It also refreshes the Cockpit asset version markers so
the new UI is loaded immediately after update.
