# SpawnWP 0.5.41

This release delivers the explicit module-data purge controls with refreshed Cockpit cache markers.
Normal uninstall keeps module-owned state for a later reinstall; “Uninstall and delete data” and
`--purge` permanently remove it, and Demo Launcher blocks purging while active demos still exist.
