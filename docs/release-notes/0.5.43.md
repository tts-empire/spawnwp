# SpawnWP 0.5.43

PHP 8.5 is now available throughout SpawnWP: new-site creation, blueprint manifests, captured
blueprints, per-site switching, Cockpit controls and the CLI all accept it. PHP 8.3 remains the
default, so existing installations and unattended workflows do not change runtime automatically.

The PHP 8.5 image uses the same extension and development-tool contract as the existing PHP
images. Documentation and public compatibility pages have been updated to show the complete
7.4 legacy / 8.2 / 8.3 / 8.4 / 8.5 matrix. SpawnWP Deploy 0.3.7 adds PHP 8.5 to
blueprints captured from an existing WordPress installation.

Pinned WordPress builds now use the official ZIP archive explicitly through WP-CLI. This retains
the upstream hash verification while preserving the long file paths used by current WordPress
cores. Builds clear the bundled core first to prevent leftovers from a newer version, while
preserving Docker's configuration template so the first boot still generates `wp-config.php`.
