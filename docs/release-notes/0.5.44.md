# SpawnWP 0.5.44

SpawnWP keeps enforcing RAM admission by default. Root operators on a single-tenant development or
test host can now opt into advisory admission with `SPAWNWP_RAM_ADMISSION=advisory` in
`/etc/spawnwp/config.env`.

Advisory admission allows site creation, **Up** and increases to a running site's PHP memory even
when the committed container limits exceed the calculated physical-RAM budget. Cockpit marks the
host as advisory/overcommitted and warns about swap pressure and OOM risk. Docker cgroup limits,
disk limits, site quotas and operational error handling are unchanged; swap is not treated as a
guaranteed capacity source. An absent or invalid setting remains enforcing.
