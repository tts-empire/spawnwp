# SpawnWP 0.5.49

The temporary `spawnwp-mcp` licensing fixture is not part of the core package
or marketplace. Existing validation installations are cleaned up once during
the update, while real third-party modules remain untouched.

Premium marketplace entries can now expose a signed Polar checkout URL. The
dashboard offers `Buy license` and then `Activate & install`, requiring only
the license key supplied after checkout.
