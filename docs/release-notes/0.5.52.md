# SpawnWP 0.5.52

This security release addresses PHP2Shell (CVE-2026-109618 and CVE-2026-109619) in SpawnWP-managed PHP runtimes.

### Security

- PHP 8.2, 8.3, 8.4 and 8.5 images must pass the upstream fixed-version floor at build time: 8.2.35, 8.3.36, 8.4.27 and 8.5.12 respectively.
- New deployments and PHP image refreshes pull the latest base image before building. A pinned WordPress version remains pinned.
- The Cockpit reports the full PHP version and patch status of running PHP and Adminer containers. Vulnerable or unverified runtimes show a persistent warning.
- PHP 7.4 remains available only after explicit risk acceptance for the exact cached image. Use it only for a non-internet-facing, isolated LAB environment; it has no verified upstream fixed release.
- Adminer updates are prepared and verified first, then applied per site. Applying an update recreates only the Adminer container; the PHP and database containers are not restarted.

### Operations

- Open **System → PHP images** and use **Prepare update** for each affected PHP image. Review the image status on the site card, then use that site's restart or PHP switch controls to apply the rebuilt image.
- In **System → Adminer image**, prepare the current image. On each affected site, use **Update Adminer** to apply it and verify the resulting runtime.
- Existing containers are not changed just by installing this SpawnWP release or preparing an image. After applying the updates, confirm every internet-facing PHP and Adminer runtime reports **Patched**.

PHP2Shell upstream guidance and fixed release floors: [NCSC-NL/php2shell](https://github.com/NCSC-NL/php2shell).
