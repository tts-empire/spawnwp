Demo Launcher for theme and plugin makers

Let visitors try your WordPress product in a private demo.

Give a product page a real, working WordPress environment without handing out a permanent site. Demo Launcher turns a captured blueprint into a protected, expiring demo URL on your own SpawnWP server.

The complete loop

From product page click to disposable WordPress site.

  1. Capture your baseline

    Prepare a WordPress site with your theme, plugin, settings and sample content, then capture it as a reusable SpawnWP blueprint.

  2. Create one campaign URL

    Install the optional signed Demo Launcher module, choose the blueprint, set a lifetime and reserve the number of concurrent demo slots.

  3. Link “Request demo”

    Place the campaign URL behind a button on your theme or plugin product page. Visitors request a site only when they are ready to try it.

  4. Protect every request

    Cloudflare Turnstile, CSRF checks, rate limits and a durable queue keep anonymous traffic from becoming uncontrolled provisioning.

  5. Let visitors explore

    Each accepted request receives a temporary front-end URL and, when enabled, a restricted single-use admin link for the product workflow.

  6. Expire and clean up

    When the configured lifetime ends, the core-managed site is cleaned up. Your reusable blueprint and campaign settings remain available for the next visitor.

Built for product pages

A demo that answers the questions screenshots cannot.

Show the real interface

Let a prospective customer click through the theme or plugin in WordPress instead of relying on a static gallery or a video.

Keep the baseline repeatable

Every request starts from the same captured blueprint, so a visitor cannot permanently change the next visitor’s starting point.

Set the cost boundary

Campaign lifetime and concurrent slots make the resource budget explicit. Increase capacity when a launch needs it, then scale it back.

Keep access temporary

The module returns short-lived bearer URLs, stores only hashes for access and rate limiting, and never sends a reusable WordPress password by email.

Self-hosted by design

Your product demo runs on infrastructure you control.

SpawnWP remains the runtime and lifecycle layer on your Debian or Ubuntu server. Demo Launcher is a separately signed optional module that mediates public requests without turning the core cockpit into an anonymous provisioning endpoint.

That gives you control over data, capacity, retention and the product experience — while keeping server operations, DNS, TLS and abuse protection your responsibility.

Cloudflare Turnstile is required.

It is a third-party anti-abuse service. Add the appropriate privacy disclosure and replace the official test keys before sharing a campaign publicly.

Know the boundary

Good for demos. Not a production storefront.

A good fit

Theme and plugin product pages

Give visitors a safe way to inspect a configured product, try its settings and see captured email behavior.

A good fit

Launches and review access

Create controlled temporary environments for a release, a partner review or a support reproduction.

Not the goal

Permanent customer hosting

Use a production host for durable sites, billing, backups and customer data. SpawnWP demos are isolated and disposable.
